# Documentaryclub

Build a polished mobile-first interactive documentary discovery website called Documentary Club. Curated 2022-2026 award-winning documentary films, emphasizing extraordinary true stories, survival, adventure, human psychology, obscure fascinating subjects rather than AI/tech or celebrity. Include Beyond Utopia, Fire of Love, The Remarkable Life of Ibelin, Skywalkers A Love Story, 20 Days in Mariupol, The Eternal Memory, The Territory, Daughters, Sugarcane, Four Daughters, The Pez Outlaw, The Perfect Neighbor, The Contestant, The Mission, The Greatest Night in Pop, The Volcano Rescue from Whakaari, Fantastic Fungi (exception older). Beautiful cinematic Netflix-like card carousel with poster art, synopsis, year, awards, genre, duration where verified, and Watch Trailer action linking to verified official YouTube trailer (search YouTube fallback if no verified URL, never fake video IDs). Swipe/keyboard next and previous, filter categories, shortlist favorites and watched with localStorage, easy links to find streaming availability in Ireland via JustWatch search, no invented awards or ratings, tasteful dark UI, responsive. Start with curated data and make fully usable without sign-in.
